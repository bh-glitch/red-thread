# Red Thread — current build decisions

- The user's follow-up expands the original three-person vertical slice to five suspects. Only Sam, Marcus, and Priya were named in the detailed demo brief. Elena Ruiz (owner) and Theo Park (IT contractor) are newly authored innocent contacts, each with their own alibi and unrelated secret. The two decisive clues and culprit stay coherent.
- The application remains a local Vite/React/TypeScript/Tailwind/Framer Motion/Zustand frontend with Python 3.11/FastAPI. Sites cannot host this exact Python backend, so no incomplete static-only cloud deployment is published. `make dev` runs both servers; `make serve` serves the built frontend and API through FastAPI.
- The evidence room is now dark, with an overhead warm lamp, vignette, narrow notebook rail, and fewer text labels. Red strings are still earned; SVG endpoints are measured from actual pins, including the document entrance animation. The call screen retains the portrait, subtitles, suggested/evidence questions, and essential interaction controls.
- Calm character audio plays at 1×; guarded and strained deliveries play at 1.1×, with pitch preserved. Browser fallback uses the same rate when the voice response supplies delivery metadata. Calls use the original static photographs.
- This Apple Silicon Mac has 16 GB memory and an existing Ollama installation with Qwen 3.5 4B. The local configuration selects that installed model for live character dialogue, with thinking disabled and a 4K context. No large chat-model download was needed. Each live character now generates their own dialogue from a dedicated prompt and isolated history. The director validates disclosure permissions and the guilty person's two-clue confession gate.
- Expressive Qwen3-TTS 1.7B CustomVoice (4-bit MLX) is the local default. Kokoro-82M ONNX remains an optional faster engine. Missing weights never trigger a cloud speech request. `make dev` installs and validates missing model files automatically; optional `auto` and `gemini` modes remain available by explicit configuration. Local voices use no hosted API quota. CPU/GPU and memory remain practical limits; “local” does not mean unlimited computation.
- Explicit Gemini mode remains available with the user's existing key, which is preserved in the ignored `.env`. Gemini TTS uses v1beta because google-genai 3.3 defaults to v1, which rejects preview speechConfig. Successful live Gemini samples were verified in the previous revision. On provider failure, installed Kokoro supplies audio; quota errors pause cloud attempts for 60 seconds.
- Audio is cached in memory for 15 minutes, bounded by 12 MB / 40 entries. Only lines actually issued to the current player session can be voiced. The cliffhanger is authorized only after reveal. Cancelling, muting, or leaving a call stops playback and prevents delayed speech.
- For future fully local voice input, Whisper Turbo through whisper.cpp is recommended for this Mac. This revision keeps browser speech recognition for microphone input. The user's comparison table describes STT; character output uses local Qwen3-TTS.
- All private case material stays in backend/. Public case projection contains no private slices, guilty flag, or sealed timeline. Sessions use random HttpOnly SameSite cookies and expire after two hours; local saves restore the investigation after backend restarts. Provider prompts do not cross-contaminate suspects' private stories.
- Nessie data remains an explicitly labeled fixture because no banking key has been supplied. The existing seed/readback/cache path is preserved. Display times are authored metadata because Nessie stores purchase dates. The seeder is not run automatically.
- `make local-setup` downloads the pinned Qwen3-TTS MLX weights and verifies a local SHA-256 manifest. Weights are ignored by source control. Runtime dependencies and frontend dependencies are locked; voice/quota and Ollama regression tests use mocks rather than the user's API quota.

- Live dialogue no longer selects an authored answer before calling the model. Five actor prompts share director rules and receive only their own permitted facts, prior admissions, and conversation history. The original scripted path remains for explicit demo mode and generation failures, which are reported to the client.
- Per-player histories, evidence, pressure, trust, and admissions are saved to an ignored local SQLite database and restored with the existing session cookie after a backend restart.

- The latest voice preference selects Gemini 3.8 Flash-Lite TTS first, with automatic warm Qwen3-TTS fallback. Approved speech is prefetched during subtitle delivery, deduplicated, and cached across restarts. Slow cloud work overlaps local generation instead of adding a full serial fallback delay. Conversation stays on Ollama.

- The investigation board zooms and pans (keys + / − / 0 / arrows, trackpad pinch or ctrl+wheel, drag while zoomed). Optional hand control (off by default, "Hand control" under the board) uses MediaPipe HandLandmarker 1.1.1 entirely in the browser; the WASM runtime and SHA-256-verified hand model are installed into public/ by scripts/setup_hands.mjs (run by `make dev`). Gestures: pinch-and-open clicks, pinch-drag pans, pinch-hold zooms onto a person, open palm zooms out. Two-hand pinch zooms. Only one hand is tracked normally (with two, MediaPipe re-runs palm detection every frame: measured 60 ms vs 11 ms per frame); the second hand is tracked only while a board pinch is held and for 1.5 s after. While a call or any popup is open, the cursor floats above it and targets that dialog's buttons (pinch to choose; a fist talks like holding Space; an open palm held still for 1 s hangs up / closes); board pan/zoom gestures resume when it closes. No camera frames leave the machine.

- Popups inside the shared AnimatePresence carry unique keys (missing keys made the call window replay its enter/exit animation — the flicker). The call window has a fixed size with the reply anchored at the top, page scroll is locked while any popup is open, and the dialog container shows no focus ring.

- Character dialogue is now Gemini first, Ollama second (`CHAT_PROVIDER=auto`). `gemini-2.5-flash` had been retired (404), so the default is `gemini-3.5-flash-lite` (~1 s per reply in testing, vs ~1.5 s warm / ~9 s cold for local Qwen). Each turn: Gemini (9 s), then Ollama (18 s), then the scripted fallback, within 26 s. A 429 pauses Gemini for 60 s, a 503 for 20 s. The Gemini Game Master router runs only when `CHAT_PROVIDER=gemini` is pinned, to save free-tier requests. The backend log names the provider and time for each reply.
- On desktop the game screen fits the window and never scrolls; on short windows the pinned cards scale down (`--board-fit`, min 55%) instead of overlapping.
- Hand clicks default to "point and shoot": the index fingertip steers, and tapping the thumb onto the side of the index finger clicks, so the pointing finger (and cursor) stays still during the click. Pinch remains selectable ("Click:" toggle under the board, remembered per browser). A press needs the thumb to have been seen apart first, the outlined target is sticky against small wobbles, and the click always hits the target that was outlined when the press began.
- The finger-gun click didn't work in practice. The default hand click is now a peace sign (index + middle up, ring + pinky curled) held still for 1 s, with a loading ring. The cursor follows the index/middle knuckles, so changing finger shape never moves it; the outlined target locks when the count starts; drifting more than 40 px restarts the count. Pinch-drag still pans and pinch-hold still zooms. Pinch click stays selectable via the "Click:" toggle.
- Hand click is fixed to the peace sign (no style switch in the UI). "Hand control: on/off" and "Hand guide" are large buttons under the board; the guide pops up whenever hand control is turned on unless "Don't show this" is ticked (remembered per browser). The whole suspect card (frame and caption, not just the photo) calls the person and shows the hover lift + "Call" overlay; its Suspect/Cleared tags still work on their own.
- 🤙 ("call me": thumb + pinky out, other fingers curled) is hold-to-talk everywhere: on the board it holds the bottom-bar voice-command mic, in calls the call mic; dropping it sends. A fist still talks in calls. Both mic buttons accept hand presses (pointer capture is optional).
- The board is taller on desktop (less space above; Cross-examine moved into the row of buttons directly under the board). Red-thread labels are HTML paper tags (15px) over the board instead of text inside the stretched SVG, which had squashed them.
- Background music: the user's "NoCopyright Thriller and Tension Music" clip (57 s, served from public/audio/thriller-tension.mp3) loops at 30% volume (lowered from 40%), starting when the player clicks "Open case file" (silent during the opening letter). The game's mute button pauses and resumes it.
- Layout clean-up: the sidebar (brief / evidence locker / notes / call log) and "Expand board" are removed; a "Case brief" button in the toolbar re-opens the opening letter and briefing in a popup. The keyboard zoom hint is gone (keys still work). "0 of 2 clues" is now two named slots ("? Undiscovered" → "Bank record" / "Witness statement", clickable once found).
- Reloading the page starts the case over (calls /reset when the browser reports a reload); opening the game normally still resumes it.
- The board lamp flickers three times every 13 seconds (off for reduced-motion users). Suspect names use the typewriter face (Special Elite) instead of Permanent Marker, and roles are 10–12px instead of 7px.
- The product is now **Red Thread** (title, logo, opening letter, loading screen, server title, AI prompts, README, package name). Internal identifiers (`ledger_session` cookie, `LEDGER_SESSION_DB`) are unchanged so saves and .env keep working. The logo is "Red Thread" in Cormorant Garamond with an italic red "Red" and a drawn red thread underline.
- The Permanent Marker font is retired everywhere (`--hand` now maps to Special Elite). Notifications sit top-centre under the lamp (framer-motion's transform had been overriding the old centring). Suspect/Cleared tags are 12px buttons. The $48,750 note is larger, stamped MISSING, wrapped in red thread with a knot, and glows softly.

The yellow letter screen has ← / → arrows (and arrow keys, and dots) to flip between cases; switching starts that case fresh (`POST /case/select`). Saves remember their case. - Case 002 uses a rainy Poconos lodge setting with a compact **brown cork board**, matching the original material. A compressed, generated photograph (`public/scenes/pocono-rain-window.jpg`) replaces the illustrated trees. Six small glass droplets descend over 31–46 seconds (three on mobile), with no video or JavaScript frame loop.
